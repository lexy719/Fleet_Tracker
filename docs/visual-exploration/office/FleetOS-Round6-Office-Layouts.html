FleetOS · Round 6 · desligado de tudo o que fizemos

15 ecrãs completos, 15 linguagens de design diferentes

Nenhum reutiliza o shell, o papel creme, o verde FleetOS, os desenhos técnicos ou os mapas desenrolados. Cada um parte de uma ferramenta que um funcionário de escritório já conhece — email, Trello, Excel, calendário, Project, chat — e mostra o mesmo dia de operação.

N-01 · linguagem
Inbox · triage what needs me
Clean SaaS · Inter · blue · white
Modelo
Email-style three panes: folders, alert list, reading pane
Porque é fácil para o escritório · ★★★★★
Every office worker already knows this. The alerts are the 'emails'; open one and act with big buttons. Lowest learning curve.
N-02 · linguagem
Board · transports by stage
Trello-like · DM Sans · purple · grey canvas
Modelo
Kanban columns, drag cards between stages
Porque é fácil para o escritório · ★★★★★
Planning becomes moving cards. Status is position, not a label. Very easy to explain to new staff.
N-03 · linguagem
Grid · everything in one sheet
Airtable-like · IBM Plex Sans · green · dense grid
Modelo
Spreadsheet with filters, grouping, coloured pills, inline edit
Porque é fácil para o escritório · ★★★★★
Office workers live in Excel. Sortable, filterable, editable in place, exportable. Power without training.
N-04 · linguagem
Calendar · who drives when
Google-Calendar-like · Roboto · teal · day columns
Modelo
Week calendar, drivers as coloured events; click empty slot to assign
Porque é fácil para o escritório · ★★★★★
Scheduling in the tool everybody already uses for meetings. Conflicts are overlaps; free time is white space.
N-05 · linguagem
Gantt · plan the week
MS-Project-like · Source Sans 3 · orange · toolbar ribbon
Modelo
Resource rows (trucks) × days, bars draggable, ribbon toolbar
Porque é fácil para o escritório · ★★★★☆
Planners see utilisation and gaps across the week; drag a transport to another truck. Familiar to anyone who used Project.
N-06 · linguagem
Dark list · keyboard-first
Linear-like · Inter · indigo · dark
Modelo
Sidebar + list with keyboard shortcuts + command palette
Porque é fácil para o escritório · ★★★☆☆
For the fast dispatcher who lives on the keyboard: ⌘K to do anything, J/K to move, single-key actions shown in rows.
N-07 · linguagem
Live map · tap a truck
Uber-Freight-like · Manrope · black + lime · rounded
Modelo
Full map, floating list panel, big rounded detail sheet
Porque é fácil para o escritório · ★★★★☆
Feels like apps everyone uses on the phone. Answers 'where is it' instantly; detail slides in with one tap.
N-08 · linguagem
Assistant · ask in plain words
Conversational · Nunito · peach · soft
Modelo
Chat with the operation; answers come as small tables and buttons
Porque é fácil para o escritório · ★★★★☆
No menus to learn: 'who can take J-4218?' Answers carry the action buttons. Great for occasional users and managers.
N-09 · linguagem
Today · tiles + to-do
Office dashboard · Work Sans · navy + yellow
Modelo
Big number tiles, a to-do list, today's deliveries table
Porque é fácil para o escritório · ★★★★★
The manager's morning screen: how many, what's late, what to do. Readable from across the office.
N-10 · linguagem
Record · transport form
Classic business app · Inter · slate · forms
Modelo
Header with status + actions, tabs, two-column fields, activity log
Porque é fácil para o escritório · ★★★★★
Exactly how invoices and orders look in every ERP — editable fields, save, history. Zero surprise for back-office staff.
N-11 · linguagem
Checklist · today's run sheet
Productivity · Space Grotesk · green · checkboxes
Modelo
Time-ordered task list per transport with progress and big ticks
Porque é fácil para o escritório · ★★★★★
Dispatch as a checklist: things tick themselves when they happen; you only act on unchecked items with a red dot.
N-12 · linguagem
Board · high contrast
Brutalist · Archivo + JetBrains Mono · black/yellow
Modelo
Giant type wallboard for the depot screen
Porque é fácil para o escritório · ★★★★☆
For the screen on the office wall: readable from 6 m, no hover, no clutter. Problems in yellow, the rest in white on black.
N-13 · linguagem
Touch · yard tablet
Touch-first · Nunito Sans · orange · huge targets
Modelo
Two panes with 64px rows and thumb-sized buttons
Porque é fácil para o escritório · ★★★★★
For the yard or cais on a tablet: gloves-friendly buttons, one decision per screen, no tiny text.
N-14 · linguagem
Report · daily summary for the boss
Editorial print · Source Serif 4 · black · A4 rhythm
Modelo
One readable page: summary, exceptions, table, signatures
Porque é fácil para o escritório · ★★★★★
Some people want a page, not an app: emailed at 08:00 or printed for the morning meeting. Same data, zero interface.
N-15 · linguagem
Wizard · assign a driver in 3 steps
Guided flow · Plus Jakarta Sans · cyan · stepper
Modelo
Stepper with choice cards, recommendation badge, summary before confirm
Porque é fácil para o escritório · ★★★★★
For rare or risky tasks: the tool walks you through, ranks the options, and shows the consequences before you confirm.
